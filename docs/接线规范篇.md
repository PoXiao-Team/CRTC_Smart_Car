# 接线规范篇（面包板 → PCB 的电气底稿）

> 适用范围：四轮麦轮底盘 + STM32F103C8T6 + 2×DRV8833 红板 + 4×TT 马达 + 1×SG90 + 2S 电池盒 + 2 路 DC-DC。
> 本文把「面包板上怎么插」翻译成「PCB 上怎么连」，**第 6 节的网络清单就是打板要抄的网络表**。
> 状态：接线已实车跑通（见《工程日志》2026-10-14）；本文为固化与打板依据。带【待核实】的项必须现场量过才能定稿。
> **注（2026-10-15）**：打板工程的实现命名与本文略有差异——电源网对应为 `VBAT / GND / +5V / +3V3 / VM`（本文 `5V_LOGIC`→`+5V`、`3V3`→`+3V3`、`VM_5V`→`VM`）；以 `hardware/pcb/design/out/NETLIST.csv` 为准。

## 1. 面包板物理规则（4 条，上电前先验证）

| # | 规则 | 为什么必须记住 |
| --- | --- | --- |
| 1.1 | 左右各有两条纵向母线排（红=正、蓝=负），**上下两段在中间是断开的** | 不补跳线，下半块就没电 |
| 1.2 | 中间 5 个横孔（a–e / f–j）是一组，组内互通 | 所以 STM32 的 B12 和两个 STBY 能插进同一排 |
| 1.3 | 横组与横组之间不互通 | 相邻排不是同一个网络，别当同一根线用 |
| 1.4 | **左边两条母线排与右边两条母线排互不相连** | 蓝线要靠跳线连通；红线左右功能不同，跨接=短路 |

### 1.1 必须补的 5 条跳线

- 左上红 ↔ 左下红
- 右上红 ↔ 右下红
- 左上蓝 ↔ 左下蓝
- 右上蓝 ↔ 右下蓝
- **左蓝 ↔ 右蓝**（把左右负极合成同一个 GND 网络）

补完后面包板上只有这几个网络：`VBAT+`（左红）、`GND`（全部蓝线）、`VM_5V`（右红）。
逻辑 5V 不上母线，由逻辑 DC-DC 直接点到 STM32 的 5V 脚（见第 3 节）。

### 1.2 上电前的通断检查（万用表蜂鸣档）

| 检查项 | 期望结果 |
| --- | --- |
| 左上红 ↔ 左下红 | 通 |
| 4 段蓝线两两之间 | 全通 |
| 左红 ↔ 右红 | **不通**（接上了就是短路，会烧件） |
| 任意红 ↔ 任意蓝 | 不通 |

## 2. 共地（GND）规则

1. 共地 = 把所有元件的 GND 引脚连到同一个网络，目的是让所有元件的 0V 基准相同。它**不是**接大地。
2. 同一个元件上有多个 G / GND 引脚时，这些引脚在元件内部本来就是连通的，**只接其中一个即可**，其余空着。
3. 本车必须共地的对象：电池负极、两个 DC-DC 的 IN−/OUT−、STM32 的 G、两个 DRV8833 的 GND、PS2 接收器 GND、SG90 的棕/黑线。
4. 蓝线（负极）全网连通；**但左右红线不能连通**——这是本方案最容易被"顺手连上"的致命错误。

## 3. 电源树（本车最终方案）

决策：2S 电池 → ① 逻辑一路 DC-DC 供 STM32；② 电机一路大电流 DC-DC 供两个 DRV8833 的 VM 与舵机。

```
2S 电池盒 (额定 7.4V，满电 8.4V)
   │
   ├─ IN+ ──┬── DC-DC #1「逻辑路」 ── OUT+ ──▶ STM32 的 5V 引脚（板载 LDO 再出 3.3V）
   │        │                          OUT− ──▶ GND
   │        │
   │        └── DC-DC #2「电机路」 ── OUT+ ──▶ VM_5V 母线 ──┬─ DRV8833 #1 的 VM
   │                                   OUT− ──▶ GND        ├─ DRV8833 #2 的 VM
   └─ IN− ──────────────────────────────▶ GND              └─ SG90 红线
                                                            （就近并 470µF + 0.1µF）
```

四个网络的定义：

| 网络 | 电压 | 说明 |
| --- | --- | --- |
| `VBAT+` | 7.4V（满电 8.4V） | 电池正极，只进两个 DC-DC 的 IN+ |
| `GND` | 0V | 全网唯一基准，蓝线 |
| `5V_LOGIC` | 5V | DC-DC #1 输出，只给 STM32 的 5V 脚 |
| `3V3` | 3.3V | STM32 的 3.3V 脚输出，只给 PS2 接收器 VCC |
| `VM_5V` | 5V（大电流） | DC-DC #2 输出，给两个 VM + 舵机红线 |

> **规则口径**：「每车 1 个供电模块」指电池组本身；两路 DC-DC 属于稳压环节，不是第二个供电模块。如遇质疑，出示本节。

## 4. 逐件引脚表（含空脚说明）

### 4.1 电池盒

| 线 | 接到 |
| --- | --- |
| 红 | 面包板左边红线（`VBAT+`） |
| 黑 | 面包板左边蓝线（`GND`） |

### 4.2 DC-DC 模块 ×2（4 脚：IN+ / IN− / OUT+ / OUT−）

| 模块 | IN+ | IN− | OUT+ | OUT− |
| --- | --- | --- | --- | --- |
| #1 逻辑 | 左红 | 蓝线 | STM32 的 `5V` 脚 | 蓝线 |
| #2 电机 | 左红 | 蓝线 | **右红**（`VM_5V`） | 蓝线 |

- 丝印可能是 `IN+/IN−/OUT+`、`VIN+/GND/VOUT+`、`IN+/GND/OUT+`，**按丝印认，不要按线的颜色猜**。
- 两个模块的 IN−、OUT− 都在蓝线上，所以随便接哪个蓝线孔都一样，因为它们已经是同一个网络。
- 【待核实】#2 的持续输出电流。4 个 TT 马达按每通道 1.5A 估算，同时堵转约 6A；电机路 DC-DC **额定 ≥3A 为门槛、≥5A 更稳**（现有 5V mini 若为 2–3A 级，按风险 R3 对策处理，见《硬件篇》）。

> 位号说明：本文 #1/#2 = U1（+5V 路）/ U2（VM 路），见 `hardware/pcb/design/out/BOM.csv`；**V2 实物摆放编号相反**（模块1 = VM、模块2 = +5V）。对应关系：U1(+5V) ↔ 实物模块2，U2(VM) ↔ 实物模块1。**认网络名，不认编号。**

### 4.3 STM32 开发板

| 引脚 | 接到 | 说明 |
| --- | --- | --- |
| `5V` | DC-DC #1 的 OUT+ | 供电入口，板载 LDO 转 3.3V |
| `3.3V` | PS2 接收器 VCC | 只带小信号件；**绝不能**在这里接舵机 |
| `G` | 蓝线（任意一个 G） | 其余 G 空着不用接 |
| `B6` | PS2 `DAT` | 双向数据线 |
| `B5` | PS2 `CMD` | |
| `B3` | PS2 `CS` | ⚠ JTAG 复用脚，见 5.1 |
| `B4` | PS2 `CLK` | ⚠ JTAG 复用脚，见 5.1 |
| `A6 / A8` | 驱动 1 的 `AIN1 / AIN2` | 左前 |
| `A7 / A9` | 驱动 1 的 `BIN1 / BIN2` | 右前 |
| `B0 / A10` | 驱动 2 的 `AIN1 / AIN2` | 左后 |
| `B1 / A11` | 驱动 2 的 `BIN1 / BIN2` | 右后 |
| `B12` | STBY 焊点 | 与两个 DRV8833 的 STBY 同网络 |
| `B7` | SG90 橙/黄线（信号） | 50Hz PWM |

- 空着不接的：PA13/PA14（留给 SWD 下载，别占用）、PA15、其余无关 GPIO、BOOT0/BOOT1（按开发板自身跳线）。

### 4.4 DRV8833 红板 ×2

| 丝印 | 驱动 1（前轮） | 驱动 2（后轮） |
| --- | --- | --- |
| `VM` | 右红（`VM_5V`） | 右红（`VM_5V`） |
| `GND` | 蓝线 | 蓝线 |
| `AIN1` | A6 | B0 |
| `AIN2` | A8 | A10 |
| `BIN1` | A7 | B1 |
| `BIN2` | A9 | A11 |
| `STBY`（也叫 `SLP` / `nSLEEP`） | STBY 焊点 | STBY 焊点 |
| `AOUT1 / AOUT2` | 左前马达 | 左后马达 |
| `BOUT1 / BOUT2` | 右前马达 | 右后马达（**实物上是 B02 → B01 的顺序，是调转向调出来的，不要"纠正"它**） |

- 【待核实】红板上如果还有 `VCC` / `VDD` / `3V3` 丝印，必须接到 3.3V，**不能悬空**，否则通道可能不出输出。只有 `VM/GND/AIN/BIN/STBY/AOUT/BOUT` 的板子则无需另接逻辑供电。
- `STBY` 不能悬空：悬空时芯片状态不确定，通道可能被禁用。接 B12 是正确做法。

### 4.5 TT 马达 ×4

- 每个马达只接 2 根线到 DRV8833 的 AOUT/BOUT，**不需要额外供电**（DRV8833 从 VM 取电）。
- 麦轮必须 X 型布局；装配完后必须逐轮验证转向（见第 7 节 Step 6）。
- **线不要焊死在驱动板上**，用可插拔端子，转向不对随时对调两根线（**V2 实际取舍：不装马达端子 J2~J5，马达线直接焊在 DRV8833 输出针上，换向靠拆焊或软件符号位**，见《工程日志》10-17）。

### 4.6 SG90 舵机

| 线色 | 接到 |
| --- | --- |
| 橙 / 黄 | STM32 的 `B7` |
| 红 | 右红（`VM_5V`） |
| 棕 / 黑 | 蓝线（`GND`） |

- 去耦：舵机接口旁就近并 470µF / 10V 电解 + 0.1µF 陶瓷（**V2 实际：本版省略去耦电容 C1~C6**——成品模块自带小去耦、面包板未加亦跑通；装车后若复位/抖动再补焊，见《工程日志》10-17 取舍①）。
- 如果出现「马达一动舵机就抖」或主控复位：把舵机红线改到 DC-DC #1 的输出（逻辑 5V 支路），或单开一路。

### 4.7 PS2 接收器

| 接收器 | 接到 |
| --- | --- |
| `DAT` | STM32 `B6` |
| `CMD` | STM32 `B5` |
| `CS` | STM32 `B3` |
| `CLK` | STM32 `B4` |
| `GND` | 蓝线（或 STM32 另一个 G，同一网络） |
| `VCC` | STM32 `3.3V` |

- 【待核实】接收器的供电电压（部分模块必须 5V）。你已按 3.3V 跑通，就保持现状，但把实测值填进第 8 节回填表。
- `DAT` 是**双向**线（不是普通 MOSI），固件里要按双向 IO 处理；B6 不要被其它外设占用。

## 5. 已识别的冲突与坑

### 5.1 PB3 / PB4 是 JTAG 复用脚（重点）

STM32F103 复位后默认使能 JTAG，`PB3 = JTDO`、`PB4 = NJTRST`，此时**不能**当普通 IO 用。

- 你现在 PS2 能通信，说明固件里已经关了 JTAG、只保留 SWD（AFIO 的 `SWJ_CFG = 010`，HAL 上是 `__HAL_AFIO_REMAP_SWJ_NOJTAG()`）。
- **风险提醒**：换固件、重新生成工程、改用 CubeMX 重新配置时，这段配置必须保留，否则 PS2 会立刻失效，而现象是"代码看起来没错但不通信"。
- 备选方案：把 `CS/CLK` 改到 PB8/PB9 或 PA4/PA5，彻底避开这个坑。

### 5.2 其它必踩项

| # | 坑 | 规避 |
| --- | --- | --- |
| a | 左右红线被跨接，2S 电压直接怼到 5V 网络 | 会烧 DRV8833 / 舵机 / STM32；上电前必做 1.2 节的通断检查 |
| b | 舵机与 STM32 共用 5V 支路导致跌落 | 本方案已分双支路（见第 3 节），不要再合并 |
| c | 4 个马达同时堵转 ≈ 6A，18650 欠压 → 主控复位 | 软件加斜坡加速 + PWM 上限；双支路 + 大电容 |
| d | 18650 极性反接直接烧件 | 打板时电池入口丝印画大号 `+ / −`，串一个肖特基或 P-MOS 做反接保护 |
| e | TT 马达线焊死 | 用 2P 端子，方便调转向 |
| f | 软件没做失联保护 | 已有文档规定：断连 500ms 内停车 |

## 6. 需要「一个焊点接多条线」的网络清单（打板核心）

你说得对：**不要在线材上把三条线焊成一坨，而是在板子上做一个焊盘，把线焊进焊盘**。PCB 上的正确形式如下表最后一列。

| 网络 | 谁连进来 | 面包板上的样子 | PCB 上的做法 |
| --- | --- | --- | --- |
| `VBAT+` | 电池正、DC-DC#1 IN+、DC-DC#2 IN+ | 左红母线 | 输入端子 + ≥2mm 走线；再用 **1×3 排针焊盘** 做分支点 |
| `GND` | 电池负、两 DC-DC 的 IN−/OUT−、STM32 G、两 DRV8833 GND、PS2 GND、SG90 棕 | 左右蓝母线 | **整板铺铜**，不用焊点堆线；每个接口附近一个 GND 测试点即可 |
| `5V_LOGIC` | DC-DC#1 OUT+、STM32 5V | 直连 | 短线 + **1×2 排针**做测试点 |
| `3V3` | STM32 3.3V、PS2 VCC | 直连 | 短线 + **1×2 排针**做测试点 |
| `VM_5V` | DC-DC#2 OUT+、驱动1 VM、驱动2 VM、SG90 红 | 右红母线 | ≥3mm 走线（或铺铜）+ **1×4 排针焊盘**（**V2 实际：主干 1.0mm/40mil + 双面铺 GND**；本节 ≥2/≥3mm 为 V1 教程稿口径） |
| `STBY` | STM32 B12、驱动1 STBY、驱动2 STBY | 同一排 5 孔 | **1×3 排针焊盘**：三个孔在板上已连成一网，三条线各焊一孔 |
| 其余信号 | 一对一 | 杜邦线 | 普通走线，0.25–0.4mm 足够 |

要点：**焊点上永远是「线 → 焊盘」，不是「线 → 线」**。铜箔在板内已经把该连的连好了。

## 7. 上电验收流程（每次改完线都走一遍）

| Step | 操作 | 通过标准 |
| --- | --- | --- |
| 0 | 断电、拔电池 | — |
| 1 | 万用表通断：任意红 ↔ 任意蓝 | 必须不通 |
| 2 | 只接电池 + 两个 DC-DC，测输出电压 | `5V_LOGIC` 与 `VM_5V` 达到目标值【待回填】 |
| 3 | 插 STM32，只跑闪灯 | 供电正常、不复位 |
| 4 | 插 PS2 接收器，读手柄 | SPI 与 3.3V 正常 |
