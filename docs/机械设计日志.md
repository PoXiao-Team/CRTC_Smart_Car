# CRTC_Smart_Car 机械结构设计日志

## 1. 抓取机构方案选型与迭代

### 1.1 方案对比与选择（机械臂 vs 勾子 vs 铲子）
在最初始的机械结构设计中，团队曾探讨过多种抓取方块的方案。首先考虑了多轴机械臂，但经过初步评估，机械臂结构复杂，组装和调试耗时极长，且单次抓取效率低，对操作手的精细控制要求极高，因此在有限的一个月备赛期内被放弃。随后考虑了钩子机构，但发现钩子容易在转移方块时抓脱，同样需要极高的操作精度。结合整车初始尺寸不得超过190×210×290mm的严格规则限制，以及我们最终确定使用的“高40mm、长255mm”的底盘，我们最终决定采用“铲子”方案。

### 1.2 第一版铲子设计：水平舵机与护栏结构的尝试
确定铲子方案后，为节省空间，我最初将舵机安排在铲子后端的正中间，并在铲子的后端（即连接舵机的部位）设计了一个竖直平面。第一版铲子在铲面（斜坡部分）和底端（铲方块的水平面，位于斜坡下方）都做了护栏，底端做了斜面，以方便铲起方块。但在方案验证中考虑到地面与方块的摩擦较小，预计需要将方块推至墙面才能顺利铲起，这会产生铲子翻转、方块滑出的风险，因此护栏的限位和防滑出设计尤为关键。

在非收起状态下，为连接舵机摇臂，我设计了水平凹陷和相应孔位，预计将舵机的长边平行于底盘放置（即舵机平放，直接置于底盘上）。铲入方块后，舵机转动90度，后端的竖直面变为水平，罩在舵机上面，方块经过斜坡下滑，通过后端的水平面滑入底盘。但在实际设计推演中发现，这种方法由于后端水平面过低，在有限空间内能够收集的方块数目非常有限，无法满足比赛的高效抢分需求。

### 1.3 第二版铲子设计：弧形滑坡与竖直舵机布局
为了解决空间利用率低和翻转高度受限的问题，我启动了第二版铲子的迭代设计。改“斜状滑坡”为“弧形”，核心目的是为了省空间，同时圆弧形更有利于方块顺畅滑下。同时，将舵机的短边平行于底盘放置（即由平放改为侧立竖直放置），铲子上连接摇臂的凹陷部分也相应设计成了适配竖直舵机的形态，并提前预留了充足的物理空间，严格防止铲子旋转时与舵机和支架的部分发生干涉冲突。

在第一版的基础上，我减少了铲子的整体厚度，以便于舵机更顺畅地旋转；同时加宽了铲面和底端（铲方块的水平面），取消了底端的护栏，设计了底端侧面的斜面。这一改动不仅进一步压缩了整体尺寸，更极大地降低了操作手的操作精度要求，提升了比赛中的容错率。

### 1.4 舵机支架的精细化设计与公差考量
在支架设计中，我深刻体会到3D打印实际精度与理论模型的差异。为了匹配实物，我在设计时预留了1-2毫米的公差。考虑到舵机连线的突出部分会占用空间，我提前在支架上设置了缺口，以便线材顺利放入。

在装配逻辑上，必须严格执行“底盘安装好支架 -> 支架连接好舵机 -> 舵机连接好铲子”的顺序，且最终要达到“铲子末端高度与地面重合”的物理状态。为了实现这一目标，我将支架上与舵机连接的部分进行了下沉处理，并提前预留好舵机放入的进口，确保了组装的可达性和最终的贴合度。

## 2. 方块收纳舱空间布局设计

### 2.1 空间布局逻辑与公差预留
由于车后半部分需要放置沉重的18650电池组和STM32主控板、驱动板等核心电路，留给方块收纳的空间十分有限。为了在有限空间内尽可能多地收集方块，我针对收纳盒进行了专门的空间优化设计。

考虑到铲入方块时，方块在车内的最终停留位置不够精准，极有可能发生偏移和堆叠不齐，我在设计盒子时，两层的长宽都提前预留了10-20mm的余量。这种容错设计能最大化利用空间，尽可能保证理论上的12个方块收集目标得以实现。

### 2.2 阶梯式收纳舱设计
利用车轮上方剩余的空间，我设计了一种“下窄上宽”的收纳舱结构：
- **下层（下窄）**：设计时错开车轮位置，并预留连接车头舵机的走线空间，该层可容纳4个方块。
- **上层（上宽）**：充分利用车轮上方的空间进行横向扩展，该层可容纳8个方块。
- **理论总容量**：理论上该收纳舱最多可装载12个方块，极大地提升了单局的收集上限。

## 3. 底盘组装与行走机构搭建

### 3.1 紧固件选型与防松措施
底盘与TT马达的组装工作，选用了M3内六角螺丝，并配合垫片、弹片（弹簧垫圈）进行紧固。使用防松组合能有效应对比赛场地中频繁碰撞导致的震动，防止螺丝松脱，保障车辆在激烈对抗中的结构稳定性。

### 3.2 麦克纳姆轮安装与调控
在行走机构的搭建上，选用了麦克纳姆轮以实现全向移动。在安装时，严格按照“X形”进行布局安装。之所以选择X形而非O形，是因为X形布局在各个方向上的受力更加均匀，左右平移时非常平稳，方便电控队友在后续进行底盘运动学调控时能够更精准地实现平移和微调，从而提升赛场上抢方块的灵活性。随后，我完成了相关线材的焊接与初步整理工作。
