## 硬件兼容性分析

### 功能描述

对"驱动能力、电源支路、逻辑电平、共地"四类兼容性问题做初判，提前排除会烧件或复位的问题（对应风险清单 R5–R8）。

### 开发历程（初判结论）

| 问题 | 判断 | 依据 |
| --- | --- | --- |
| DRV8833 是否适合实际电机 | 大概率适合，需实测 | 官方套件将 DRV8833 与 TT 马达配成一套；每通道持续约 1.5A 级，TT 马达堵转电流需实测【待实测】 |
| 单个驱动模块能否驱动所需电机数 | 不能，需 2 个 | DRV8833 为双通道，4 个电机需 2 个模块；现有 4 个，够用且余 2 个备用 |
| 是否需要额外驱动模块 | 不需要 | — |
| STM32 逻辑电压兼容性 | 大概率兼容，需确认 | STM32 为 3.3V 逻辑；TT 马达与舵机只接收 PWM；PS2 接收器与 DRV8833 逻辑供电需实测【待实测】 |
| 舵机电源是否足够 | 存在风险 | 5V mini 降压通常 2A 级；MG995 单只堵转可达 1.5–2.5A，两只同时堵转几乎必然拉低 5V |
| 电机启动/堵转是否引起复位 | 高风险 | 4 个 TT 马达同时启动的浪涌会拉低电池电压；STM32 与电机同节点取电极易复位 |
| 是否需要独立电源支路 | 需要，至少两条 | 电机支路与逻辑+舵机支路分开，各自就近加去耦电容（**初判**；最终设计相反：舵机挂 VM 电机路——V2 审查已把"舵机电源误接 +5V"修正为接 VM，见《工程日志》10-17） |
| 哪些必须共地 | 全部 | STM32、DRV8833、5V 降压、舵机、PS2 接收器、电池负极必须连通 |
| 电池相关电气风险 | 三项 | ① 18650 极性接反会直接烧模块；② 2S 无保护板时过放损坏电芯；③ 锂电必须用专用充电器（已到手的双槽充电器可用） |

硬件逐件分析表（参数与影响）：

| 部件 | 当前信息 | 需要确认的参数 | 对项目的影响 |
| --- | --- | --- | --- |
| 麦克纳姆轮 | 黄色花纹万向轮，带安装支架 | 轮径是否 60mm；轮毂轴孔规格；是否已配 TT 联轴器 | 决定底盘尺寸、离地间隙、电机选型 |
| 面包板 ×2 | MB-102 400 孔 | — | 仅桌面测试用，规则建议上车用 PCB |
| DRV8833 ×4 | 红板 | VM 输入范围；每通道持续/峰值电流；SLP 睡眠引脚是否引出 | 决定能否驱动 TT 马达、VM 供多少伏 |
| SG90 ×4 | 180°，TIANKONGRC | 堵转扭矩；堵转电流 | 适合小机构；可满足"至少 3 个舵机转动"指标 |
| MG995 | 物资表为 180° 铁+铜齿轮 ×2 | 是否 180°；数量；堵转电流；堵转扭矩 | 决定舵机支路电流能力（**后续定案：1 号车铲子由 1×SG90 驱动**，见《机械篇》V2 设计；MG995 转为 2 号车机械臂选型核算候选【待定】） |
| 5V mini 降压 | 物资表为"黑板" ×2 | 输入范围；最大持续输出电流 | 决定能否同时带 STM32 与 MG995 |
| STM32F103C8T6 | 型号已确认（开发板_Micro_焊接） | 是否引出全部 GPIO；有无 USB 口；有无板载 USB 转串口芯片；板载 LDO 输入范围；下载接口 | 引脚分配与电脑操控链路的依据 |
| 电池组 | 黑色封装锂电 + 红黑线 | 电芯数；串并联；容量；保护板；是否 18650 | 规则限制额定 ≤7.4V、仅 1 个供电模块 |
| 18650 充电器 | YB 双槽，支持 2×3.7V | — | 只负责充电，不能替代电池保护板 |
| 杜邦线 | 公对公 / 母对公，10CM 40P | 母对母是否也有 | 规则不推荐纯杜邦线 |
| 3D 打印件 | 白色镂空立方体 ×1（道具样件）；红色铲子件 ×1（机构件） | 见《机械篇》待确认清单 | 有尺寸与安全风险 |

**安全风险汇总**：18650 极性接反烧模块；2S 无保护板的过放与短路风险；电机与 STM32 共用电源节点导致主控复位；MG995 与 STM32 共用 5V 支路导致电压跌落；3D 打印铲子件的尖锐边缘触碰安全规范（处理见《机械篇》）。

## 供电方案决策（未决 → 试跑验证）

### 功能描述

在规则红线内确定电机与逻辑供电方案：**供电模块额定电压 ≤7.4V、每台机器人仅 1 个供电模块、必须适配官方无线继电器**（P6/P8）。目标：不烧电机、不因浪涌复位、同时满足舵机瞬时电流。

### 开发历程

关键事实：

| 事实 | 数值 | 状态 |
| --- | --- | --- |
| 规则上限：供电模块额定电压 | ≤7.4V | 已确认（P6） |
| 2 节 18650 串联（2S） | 额定 7.4V / 满电 8.4V | 常识 |
| 2 节 18650 并联（2P） | 额定 3.7V / 满电 4.2V | 常识 |
| TT 马达 1:48 标称工作电压 | 通常 3–6V | 【待确认】查商品页/实测 |
| DRV8833 的 VM 输入范围 | 需查实际模块 | 【待确认】 |

三条候选路线对比：

| 方案 | 做法 | 优点 | 风险 |
| --- | --- | --- | --- |
| A 直供 2S | DRV8833 的 VM 直接接 7.4V | 最简单、成本最低 | TT 马达超压，发热、寿命、堵转电流上升 |
| **B 降压供驱动（选用）** | 电池 → 大电流降压 → VM | 电压规范、电机安全 | 需大电流降压模块：4×TT 堵转峰值约 5.5A，**额定 ≥3A 为决策门槛**（见 `design/out/线宽与电流预算.md` 风险 R3）；实物型号与额定【待回填】 |
| C 直供 + 软件限速 | VM 接 7.4V，PWM 占空比上限压到约 70%（等效约 5.2V） | 成本最低，等效约 5.2V | 靠软件兜底，堵转电流仍按 7.4V 算 |

**当前状态**：**已确认采用降压方案（候选 B）**——双路：逻辑路 DC-DC 输出 5V 供 STM32（板载 LDO 出 3.3V）；电机路 DC-DC 输出 **VM = 5.0V** 供两个 DRV8833 的 VM 与舵机（打板设计值）。实车带载运行正常（2026-10-14）。DC-DC 型号/额定电流与实测电压【待回填】。
