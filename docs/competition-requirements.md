- 2 个挂在 e3、d6 的物资架初始端（质心距地 250mm）；
- 2 个位于 d1、e8 台阶下的洞穴内（洞穴开口 70×70×50mm）；
- 1 个位于中央高地平台的焦点中心（焦点总高 70mm）。

### 矮墙对机构选型的影响

手册 P16：

- e8、d1 附属高台上有两组矮墙（每片 10×50×10mm），组内间距 **31.5mm**，组间间距 40mm；
- 焦点周围十字基座每方向两片矮墙（10×60×10mm），间距 **31.5mm**，距中心 64.25mm。

方块 30mm 与矮墙间距 31.5mm 只差 0.75mm/侧，即方块被矮墙限位卡在槽内；矮墙高 10mm，方块露出 20mm。

结论：这类方块不能靠侧推式铲子收集（铲板低于 10mm 会撞矮墙，高于 10mm 顶不过矮墙），只能向上提、夹取或上翻兜住。涉及至少 6 个能量单元（附属高台 2 个 + 焦点周围 4 个）。对中期考核不构成阻塞（中期方块携带在平地演示即可），但影响正式比赛的收集率。

## 4. 机器人技术规范

| 类别 | 规范 | 依据 |
| --- | --- | --- |
| 初始尺寸 | 长宽 ≤ 290×195mm，高 ≤ 210mm（每局正式开始时） | P6-7 / 3.3.2 |
| 任意状态尺寸 | 长宽高 ≤ 445×400×450mm，或满足直径 550mm 球体约束 | P6 / 3.3.2 |
| 重量 | ≤ 2.0kg | P7 / 3.3.2 |
| 结构强度（检录） | 150–200mm 高处底面朝下自由下落，无零件掉出 | P7 |
| 结构强度（中期指标） | 180mm 自由下落无零件掉出 | P9 |
| 电源 | 指定 18650 电池；每台机器人仅允许 1 个供电模块；供电模块额定电压 ≤ 7.4V | P6 |
| 供电模块定义 | 有且仅有一个输出接口；继电器与电池间有延长/转接线时按离电池最近端计算接口数 | P6 注 |
| 无线断电 | 必须适配官方指定无线继电器，底盘电源能在 10m 内被单独遥控切断；检录检测，遥控器上交裁判 | P8 |
| 遥控器 | 官方物资表列出 PS2 手柄；不限制使用其他自行购买的遥控器或其他控制方案（V1.5） | P6 / 3.2 |
| 通讯方式 | 蓝牙 / 2.4G / WiFi / 红外，仅可选其中一种；发射源与接收源有且仅有一组 | P6 |
| 物理安全 | 不得携带或装配任何尖锐物体，不得装易致短路、爆炸或具穿刺、破坏功能的装置 | P7 |
| 结构建议 | 建议牢固材料，避免热熔胶；建议采用集成电路板，纯杜邦线易脱落；布线不得过度裸露 | P7 |

对设计的约束：

1. 铲子存在被认定为尖锐物体的风险，前沿须钝化并做大圆角；
2. 初始尺寸 290×195×210mm 很紧，铲子须可收拢或完全在包络内；
3. 供电仅 1 个模块且额定 ≤7.4V，2 节 18650 串联（2S，额定 7.4V）是规则下的上限，不能挂两块电池、不能用 3S；
4. 无线继电器为强制件，无此件无法通过检录。

### 基础功能考核指标

每项满分 100 分，完成的队伍平分（精确到 2 位小数）。

| # | 功能名称 | 功能简述 |
| --- | --- | --- |
| 1 | 外形展示 | 至少一台具有能量单元的完整机器人机体（绕车一周） |
| 2 | 电机运动（单一） | 能完成至少一个电机的转动 |
| 3 | 电机运动（全部） | 能完成不少于 4 个电机的转动 |
| 4 | 舵机运动（单一） | 能完成至少一个舵机的转动 |
| 5 | 舵机运动（多项） | 同一台机器人能完成至少三个舵机的转动，且其可动机构能在任意非初始状态下保持相对静止 |
| 6 | 底盘运动（单一） | 能用 PS2 手柄控制至少一个底盘的水平运动（车体与手柄同时出镜或给出相关代码） |
| 7 | 底盘运动（全部） | 能用 PS2 手柄控制全部车体的水平运动 |
| 8 | 尺寸规范 | 尺寸在规则限制范围内（需展示直尺测量结果） |
| 9 | 方块携带（单一） | 使至少一颗在地面静止的方块（30×30×30mm）由非携带变为携带状态 |
| 10 | 方块携带（多项） | 在保持携带 1 块的状态下，再使至少 1 块地面方块由非携带变为携带 |
| 11 | 结构稳定性 | 从高 180mm 处底面朝下自由下落无零件掉出 |
| 12 | 规划/现有采购单 | 队伍核心部件的选型、整机成本预算 |

进阶功能最多 3 项，每项按创新度、实现难度、完成度各 3 分取平均，最高加 9 分；未完成全部基础功能则无法获得进阶加分。

指标 6、7 的文字要求使用 PS2 手柄，但括号内给出替代证明路径"或给出相关代码"；配合 P6"不限制其他控制方案"，开发阶段用电脑操控合规。中期提交建议同时给出实物演示视频、指令层代码与一页说明；时间允许则仍按 PS2 补拍一版。
