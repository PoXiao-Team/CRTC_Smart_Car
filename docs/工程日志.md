## 铲子收集机构设计与合规分析（2026-09-20 起）

### 功能描述

前端收集机构，把地面静止的 30×30×30mm 方块（约 11.29g）铲起并导入中部收纳区，使方块由"非携带"变为"携带"状态。约束条件（均来自手册，详见《赛事规则解析》）：

| 约束 | 数值 | 对设计的含义 |
| --- | --- | --- |
| 非尖锐物体（P7） | 不得携带/装配尖锐物体 | 铲板前沿与尖角必须钝化做大圆角 |
| 初始尺寸（P6） | 长宽 ≤290×195mm、高 ≤210mm | 铲子须可收拢或以非展开状态计入包络 |
| 结构强度（P7/P9） | 150–200mm（中期 180mm）跌落无零件掉出 | 外伸悬臂件需防断裂、防脱落设计 |
| 成本（P8） | 新生组整车 ≤400 元 | 驱动件复用官方物资（SG90 舵机） |

### 开发历程

- **方案选型（对比表与结论见《机械篇》）**：在多轴机械臂（结构复杂、耗时、效率低）、钩子机构（易抓脱）、铲子方案之间，结合初始尺寸限制与"高 40mm、长 255mm"的底盘条件，确定铲子方案。
- **V1 设计（水平舵机 + 护栏）**：舵机平放于铲子后端正中；铲面与底端做护栏、底端做斜面。推演发现：返回面过低导致可收集数目非常有限，且依赖"把方块推到墙面才能铲起"的工况，有翻转甩出风险 → 淘汰。
- **V2 设计（弧形滑坡 + 竖直舵机）**：斜状滑坡改弧形（省空间、利于方块下滑）；舵机由平放改侧立竖直放置；减薄铲体、加宽铲面、取消底端护栏、侧面做斜面 —— 降低操作手精度要求、提升容错率。V2 为当前主线方案。
- **舵机支架精细化设计**：预留 1–2mm 打印公差与舵机线缺口；执行"底盘 → 支架 → 舵机 → 铲子"装配顺序；支架连接处下沉处理，保证"铲子末端高度与地面重合"。
- **2026-10-11 结构分析与合规检查**（对 CAD 录屏与实物照片）：判定红色实拍件为舵机驱动翻转铲（V1 件）；识别出三个优先问题 —— 铲板前沿尖角触碰"尖锐物体"规定、件长与 290mm 初始尺寸的关系、外伸悬臂件的跌落强度风险；给出处理要求（前沿与尖角改 R3 以上圆角、可收拢设计、舵机轴加机械限位、实心填充 ≥40%）。
- **2026-10-18 装配取舍（临时过渡方案）**：3D 打印时间来不及 —— ① **铲子暂时沿用第一版（V1）打印件**，V2 改进（弧形滑坡 / 竖直舵机 / 圆角化）延期；② **装载方式以塑料箱平替**原设计的阶梯式收纳舱。两项均为临时过渡，第二版（中期考核后）分别替换为 V2 铲子与成品收纳舱，详见《机械篇》；打印前检查清单（7 项）见《机械篇》。
- **规则细节留档**：e8、d1 附属高台与焦点周围矮墙组内间距 31.5mm，方块 30mm 被限位、只能向上取出，侧推式铲子对这类方块无效（涉及至少 6 个能量单元）。不影响中期考核，影响正式比赛收集率；第一版机构不为其牺牲可靠性，列为后续迭代方向。

## 方块收纳舱设计（2026-09-20 ~ 10-07）

### 功能描述

在电池组、STM32、驱动板占据车体后部的前提下，尽可能多地收纳方块：理论目标 12 块（占全场 18 个能量单元的 2/3）。依据规则：只有对局结束时仍处"携带状态"（沿任意方向含上下都跟随运动）的道具才计分，因此收纳舱必须有挡板或锁止能力。

### 开发历程

- 针对铲入方块"最终停留位置不精准、易偏移堆叠"的问题，两层长宽均预留 10–20mm 余量，用容错设计保住理论容量。
- 最终采用"下窄上宽"阶梯式结构（详见《机械篇》）：下层错开车轮位置并预留车头舵机走线空间（4 块）；上层利用车轮上方空间横向扩展（8 块）。
- **2026-10-18 装配取舍（临时过渡）**：阶梯式收纳舱打印时间来不及，当前以**塑料箱平替**装载；第二版（中期考核后）再打印舱体替换，详见《机械篇》"当前实际"段。

## 底盘与行走机构组装

### 功能描述

四轮麦克纳姆轮底盘的实体搭建（金属折弯底盘 + TT 减速马达 ×4 + 60mm 麦轮），要求耐频繁碰撞震动、全向移动平稳。

### 开发历程（2026-10-05 ~ 10-07）

- 紧固件：底盘与 TT 马达组装选用 M3 内六角螺丝，配合垫片与弹片（弹簧垫圈）防松 —— 应对比赛场地碰撞震动导致的螺丝松脱。
- 麦轮按 **X 形**布局安装（X 形而非 O 形）：各方向受力更均匀、左右平移平稳，便于电控在运动学调控时精准实现平移与微调。
- 完成相关线材焊接与初步整理。
- 装机后的电机编号、转向符号、实测记录见《机械篇》与《硬件篇》待办（【待实测】）。

## 遥控链路与指令层设计（2026-10-11）

### 功能描述

为底盘与机构提供可演进的操作链路，最终目标为 PS2 手柄遥控（满足中期指标 6、7）。核心设计：把操作指令抽象为统一结构体 `cmd_t`，只替换数据来源，下游麦轮解算与电机、舵机控制代码保持不变：

| 阶段 | 链路 | 用途 | 状态 |
| --- | --- | --- | --- |
| A | PC → USB-TTL → UART → STM32 | 桌面调试 | 🟡 方案已定，按需使用 |
| B | PC 蓝牙串口 → HC-05 → UART → STM32 | 无线演示 | ⬜ 降为备份（PS2 已可用） |
| C | PS2 手柄 → 接收器 → SPI → STM32 | 最终方案 | ✅ 实车连接操控通过（10-14） |

### 开发历程

- 因 PS2 手柄未到货，决定先用电脑操控把底盘和机构跑通；选择"定义统一指令层、替换数据源"而非"为电脑单独写一套控制"。
- **2026-10-14 实连验证**：PS2 手柄及接收器到货，实车连接成功、操控正常（底盘运动由 PS2 控制），阶段 C 链路按设计落地。
- 定义 8 字节定长帧协议（帧头 `0xAA 0x55`，vx/vy/w/buttons/保留/异或校验），UART 115200 8N1、50Hz。
- 失联保护列为必做项：200ms 无有效帧降速、500ms 立即停 PWM 进入 FAILSAFE（依据：手册"失控后果自负"与被判恶意冲撞将断电 20s 的判罚）。
- 两条边界：有线串口只用于开发调试，正式比赛必须切换无线（蓝牙或 PS2）；最终只能保留一套无线收发链路，切换时拆除另一套。
- 协议全文、按键映射、故障速查与阶段验收标准见《遥控与指令篇》。

**5）V2 原理图重建与审查（10-16 晚 ~ 10-17 上午）。**

- 建库：按实物自建三个符号——DRV8833（16 脚，左右列按实物丝印）、mini 降压（4 脚 IN−/IN+/OUT−/OUT+）、STM32 核心板（40 脚，用于插最小系统板）。关键结论：官方"开发板"器件不是裸芯片，正是"插最小系统板"的配套件——自制 40 脚符号成立的前提是自建 40 孔封装并关联。
- 审查发现并修正（截图逐项核）：+5V 与残留旧网名 VCC 短接（16 段无名网络为路过者）、两块驱动 VM 误接 +5V、前后驱动信号配对互换、DRV 右列 GND 脚误打 ×、电机两脚同名（H 桥输出短路）、舵机电源误接 +5V（应 VM）、PS2 前后顺序待实物锁版、中文位号报错（统一改英文字母+数字）。
- 口径确认（V2）：两块降压模块按**实物摆放编号**——模块1 = VM 路（供驱动 + 舵机）、模块2 = +5V 路（供核心板）；对应原理图位号 **模块1 ↔ U2（VM）、模块2 ↔ U1（+5V）**（位号沿用 design/ 脚本体系）。接线、装配、排错一律以**网络名（VM / +5V）与位号（U1 / U2）**为准，不单独使用"模块1/2"。
- 本版三处取舍：① **省略去耦电容 C1~C6**（成品模块自带小去耦、面包板未加亦跑通；风险：马达启停/舵机堵转瞬间可能复位，装车后视情况补）；② **不装马达端子 J2~J5**（马达线直接焊在 DRV8833 模块输出针上，换向靠拆焊）；③ 保留自制 40 脚核心板符号（对应自建封装）。
- 结果：原理图 DRC 0 错，转入 PCB。

## 遥控操作与铲子示教（2026-10-17）

### 功能描述

PS2 手柄的完整操作方案（含铲子"示教-回放"），已实车验证并固化为队内操作手册（全文见《遥控与指令篇》"实际操作手册"板块）。两项关键设计：

- **R1 为移动使能键**：不按 R1 电机不驱动（松开即停），构成防误触安全线；L1 = 慢速修饰；SELECT = 停轮 + 关闭舵机控制脉冲 + 清除铲子位置记录；
- **铲子示教-回放**：L2/R2 点动调位 → □ 记录"铲下位置"、○ 记录"翻倒位置" → △ 一键自动翻铲（回位 → 翻倒 → 返回）→ × 取消；避免每次手动微调舵机角度。

| 功能 | 操作方式 | 状态 |
| --- | --- | --- |
| 底盘前后 / 横移 / 斜移 | R1 + 十字键（含相邻两键组合） | ✅ 实车可用 |
| 转向 / 边移边转 | R1 + 右摇杆左右；移动时同推右摇杆 | ✅ 实车可用 |
| 慢速 | 同时按住 L1 | ✅ 实车可用 |
| 停止 / 急停式停轮 | 松开 R1；SELECT（停轮 + 关舵机脉冲 + 清位置记录） | ✅ 实车可用 |
| 铲子示教与一键翻铲 | L2/R2 点动 → □/○ 记录 → △ 自动翻铲 / × 取消 | ✅ 实车可用（操作手册固化） |
| 舵机上电自动回正（装配基线） | 开机先回正 → 再装铲子作为初始位置 | ✅ 已确认 |

### 开发历程

- 10-11：指令层设计（`cmd_t`，初版位域为"△/○ = 铲子抬起/放下、L1 = 备用键"）。
- 10-14：PS2 实连，底盘操控跑通。
- 10-17：操作方案按实车手感锁定——移动收归"R1 + 十字键"（含斜向组合与右摇杆转向）、舵机改为 L2/R2 点动 + □/○/△/× 示教回放，形成操作手册（队内使用，评委可据此复现操作）。
- 装配约束（10-17 确认）：舵机上电自动回正——必须先开机等回正、再装铲子作为初始位置；每次开机自动回初始位置。
- **10-19 装机发现（已知问题）**：所用 SG90 舵机**实际行程达不到标称 180°（略小）**——铲子"铲下 → 翻倒"有效翻转角受限；操作侧按**实际可达位置**示教（□ / ○）即可，一键翻铲不受影响；但**"舵机运动（多项）"指标受此限制，中期视频中未完成**【待实测具体角度】。
