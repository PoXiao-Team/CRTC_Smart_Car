# PCB 打板篇（嘉立创EDA 专业版 · 零基础完整流程）

> 前置：先读《接线规范篇》，第 6 节的网络清单就是本教程要抄的网络表。
> 目标产出：一块「载板」——STM32 开发板插在母座上，两个 DRV8833、两个 DC-DC、PS2 接收器、舵机、4 个马达、电池全部通过接口接上板子。
> 软件：嘉立创EDA 专业版（客户端）。不同小版本的菜单措辞可能略有差异，按关键字找即可。

## 0. 先说清楚：这块板是什么，不是什么

**是**：一块载板 / 底板。把面包板上的两根红母线、两根蓝母线，换成板内的铜箔走线与铺铜；把所有"需要连成一堆"的线，换成板上的排针焊盘阵列。

**不是**：把 STM32 芯片贴片焊上去。保留现有开发板，板上做 2.54 母座直插。

三个直接收益：

1. 模块坏了直接拔换，不用重新焊；
2. 引脚搞错只改板，不动模块（这就是为什么**必须先量实物**）；
3. 没有接触不良——面包板上最常见的"跑着跑着复位"大多来自松动插接。

**打板前必须先跑通面包板**（已达成：2026-10-14 实车跑通）。打板是把已经验证过的接线固化，不是拿板子做实验。

## 1. 打板前必须量出来的 7 组尺寸

拿游标卡尺 + 手机，每个模块**正反两面各拍一张照并标注尺寸**，画图时会反复回看。

| # | 器件 | 量什么 | 用在哪 |
| --- | --- | --- | --- |
| 1 | STM32 开发板 | 排针间距、两排之间距离、板子长宽、USB 口位置与高度、复位键位置 | 决定母座型号、USB 口开槽/放边 |
| 2 | DC-DC ×2 | 长宽、4 个焊盘间距与顺序、丝印 | 决定座子封装 |
| 3 | DRV8833 红板 ×2 | 长宽、排针行距与列距、脚数（**已实测：16，2×8**）、STBY 丝印位置 | 决定母座封装 |
| 4 | PS2 接收器 | 脚数与朝向、排针间距 | 决定排母封装 |
| 5 | 电池盒 | 长宽高、出线位置 | 决定它在底盘上怎么固定、线怎么走 |
| 6 | 底盘 | 现有安装柱孔位（孔距、M2/M3）、四个马达出线位置、四角空间 | 板子外形与安装孔 |
| 7 | 舵机 + 马达线 | 线长、接头类型 | 决定端子类型与位置 |

> **一条铁律**：所有间距都实测，不要相信"应该都是 2.54"。2.0mm 和 2.54mm 插不进去，是打板返工的第一大原因。

| 接口 | 建议用件 | 为什么 |
| --- | --- | --- |
| 电池输入 | XT30 或 KF301-2P 螺钉端子 | 电流大，杜邦线扛不住 |

| PS2 接收器 | 1×6 排母 | |
| STM32 | 2×20 或 2×24 母座（按实物） | |
| SWD 下载 | 1×4 排针（3V3 / SWDIO / SWCLK / GND） | 不用每次拔板烧录 |

## 5. 原理图阶段

### 5.1 先做 5 个「非标件」符号

现成模块在标准库里搜不到，必须自建（`文件` → `新建` → `符号`）：

| 要自建的符号 | 引脚 |
| --- | --- |
| 电池盒 | 2：`VBAT+`、`GND` |
| DC-DC 模块 | 4：`IN+`、`IN−`、`OUT+`、`OUT−` |
| DRV8833 红板 | **16（2×8，已实测）**：左列 `NC` `AIN2` `AIN1` `STBY` `BIN1` `BIN2` `NC` `GND`；右列 `VM` `NC` `GND` `AO1` `AO2` `BO2` `BO1` `GND` |
| STM32 开发板 | 按实物排针全引出，至少要有 `5V` `3.3V` `G` `B0` `B1` `B3` `B4` `B5` `B6` `B7` `B12` `A6` `A7` `A8` `A9` `A10` `A11` `PA13` `PA14` |
| PS2 接收器 | 6：`DAT` `CMD` `CS` `CLK` `VCC` `GND` |

**关键要求：符号的引脚名必须和实物丝印一字不差。** 这一步做对，后面连线几乎是抄表；这一步马虎，PCB 就等着飞线。

### 5.2 标准件直接用「立创商城」库

排针、排母、电容、电阻、端子、螺丝孔：在 `元件库` 面板搜 `排针 2.54 1x4`、`端子 KF301-2P`、`电解电容 470uF` 等，直接放置——符号、封装、3D 都自带，不用自己画。

### 5.3 画图顺序

1. 先把 **STM32 开发板**放中间；
2. 左边放电源区（电池端子、两个 DC-DC）；
3. 右边放驱动区（两个 DRV8833）；
4. 下面放接口区（电机端子 ×4、舵机、PS2 排母）；
5. 每个 GND 脚都放一个 GND 符号；电源网络用网络标签 `VBAT` / `5V_LOGIC` / `VM_5V` / `3V3` 表达流向；
6. 用连线工具（快捷键 `W`）和网络标签（`放置` → `网络标签`）连线；
7. `STBY` 那三个点：放一个 **1×3 排针**，把三个脚都接到 `STBY` 网络（画三根短线并起来）——这是给"一个焊盘接三条线"准备的位置。

### 5.4 原理图自检（ERC）

- `设计` → `检查 DRC` / `ERC`。
- 重点看三样：**单端网络**（只有一个引脚的网络，通常是漏连或标签打错）、**电源与地短路**、**引脚未连接标记**。
- 全部清零再转 PCB。

### 5.5 转 PCB

`设计` → `原理图转PCB`（有的版本叫「更新/转换原理图到 PCB」）。之后原理图与 PCB 支持交叉选择——点原理图的元件，PCB 里会高亮。

## 6. PCB 阶段

### 6.1 板框与安装孔

1. `放置` → `板框` → `矩形`，在右侧属性里输入精确尺寸（例如 100×70mm）。
2. 四角放 M3 安装孔：`放置` → `焊盘`（孔 3.2mm、盘 6mm、**不设网络**），坐标对着底盘孔位。
3. 【必做】把板框和孔位先在底盘上比一次（拿纸打印 1:1 裁下来对孔，能省掉一版废板）。

### 6.2 设计规则（先设后画）

`设计` → `设计规则`：

| 项目 | 值 |
| --- | --- |
| 默认线宽 | 0.25mm |
| 新增线宽规则 | 信号 0.25mm / 电源 1mm / 电机 2–3mm |
| 最小间距 | 0.2mm |
| 过孔 | 0.3mm 孔 / 0.6mm 盘 |
| 铺铜到焊盘间距 | 0.3mm |

### 6.3 布局（按电流走向摆，不按好看摆）

1. 顺序：电池端子 → DC-DC → `VM_5V` 母线 → DRV8833 → 电机端子，**一条直线走到底**；
2. STM32 与 PS2 接收器放在**远离电机线**的一侧；
3. 所有对外接口靠板边（线从板边走，不要横穿板面）；
4. SWD 下载排针放板边；
5. 给 STM32 的 USB 口留出缺口或放到板边，否则插不进去；
6. 去耦电容就近放置：每个 DC-DC 的输入/输出各一个电解 + 一个陶瓷；舵机接口旁 470µF + 0.1µF；STM32 母座旁 0.1µF ×2。

### 6.4 走线

- 菜单：`放置` → `走线`（快捷键 `W`）；走线过程中按 `Tab` 或在右侧属性面板改线宽；按 `V` 换层并自动放孔。
- **线宽—电流对照表**（1oz 铜、10℃ 温升、IPC-2221 粗算，短距离可适当放宽）：

| 线宽 | 约可过电流 |
| --- | --- |
| 0.25mm | 0.75A |
| 0.5mm | 1.5A |
| 1.0mm | 3A |
| 2.0mm | 6A |
| 3.0mm | 9A |

- 本板取值建议（**本节 ≥2/2–3mm 为 V1 教程稿口径；V2 实际主干 1.0mm/40mil + 双面铺 GND，见《工程日志》10-17**）：
  - `VM_5V`、`GND`（电机回路）：≥2mm，能铺铜就铺铜；
  - `VBAT`：≥2mm；
  - `5V_LOGIC`、`3V3`、信号线：0.25–0.4mm 足够；
  - `PS2_CLK` / `PS2_DAT` / `PS2_CS` 三根走一起、尽量短；
- **过孔载流**：0.3mm 孔约 1A。要过 3A，就并 3 个孔。

### 6.5 铺铜

1. `放置` → `铺铜` → 网络选 `GND` → 画一块覆盖全板的区域；顶层、底层各来一块。
2. 铺铜连接方式：`GND` 焊盘用**直连**（大电流），信号焊盘用**十字连接**（好焊）。
3. 顶层与底层的 GND 铜用一圈**缝合过孔**连起来，间距约 10mm。

### 6.6 「一个焊点接多条线」怎么做（本文最关键的一节）

对应《接线规范篇》第 6 节。做法只有一句话：**板内用铜箔连成网络，板面给每条线一个焊盘孔。**

**以 `STBY` 为例（三个点：STM32 B12、驱动1 STBY、驱动2 STBY）**

1. 原理图里放一个 `1×3` 排针，三个脚全部接到 `STBY` 网络（三脚画短线并起来）；
2. 转 PCB 后，这三个焊盘自动都属于 `STBY` 网络；
3. 用一条 1mm 宽的走线横穿这三个焊盘，或直接铺一小块铜把它们包住；
4. 装配时：B12 的线、驱动1 的 STBY 线、驱动2 的 STBY 线，**各焊进一个孔**。

结果就是你想要的：三条线没有互相焊在一起，而是焊进了同一个焊点的三个孔里。

**同理复制到其它网络**：

| 网络 | 焊盘阵列 |
| --- | --- |
| `VM_5V` | 1×4 排针：DC-DC#2 OUT+、驱动1 VM、驱动2 VM、舵机红 |
| `VBAT` | 1×3 排针：电池 +、DC-DC#1 IN+、DC-DC#2 IN+ |
| `5V_LOGIC` | 1×2 排针（兼做测试点） |
| `3V3` | 1×2 排针（兼做测试点） |
| `GND` | 不用做焊点阵：整板铺铜，任何 GND 孔都行 |

> 注意：**不要把 GND 也做成"一坨焊点"**。地的电流最大，必须走整板铺铜，焊点堆线会带来压降和噪声。

### 6.7 给第一版留后路（强烈建议）

| 后路 | 做法 | 收益 |
| --- | --- | --- |
| 分区断电排查 | 在 `VM_5V` 到每个 DRV8833 的 VM 之间串一个 **0Ω 电阻位** | 怀疑某路驱动短路时拔电阻即可隔离 |
| 舵机电源可切换 | 舵机红线前放一个 **2 针跳线（跳线帽）**，分别可接 `VM_5V` 或 `5V_LOGIC` | 出现抖动时不用改板 |
| 预留飞线点 | 每个关键网络留一个测试点焊盘 | 改错时飞线有落点 |
| IO 备用 | 两组 1×8 排针 | 以后加传感器不用重打板 |

### 6.8 丝印（装配时救命）

- 每个接口旁写清：`M1`(左前) `M2`(右前) `M3`(左后) `M4`(右后)、`VM` `GND` `5V` `3V3`；
- 电池入口画大号 `+` / `−`；
- 板边写板名 + 版本 + 日期：`CRTC Car Base V1.0 2026-10`；
- 丝印不要压在焊盘上。

### 6.9 DRC 与 3D 检查

1. `设计` → `检查 DRC`：必须 **0 错误**；间距/丝印类警告逐条确认。
2. 用「未布线网络」检查确认没有漏掉的网络。
3. `视图` → `3D预览`：重点看模块会不会相互撞、USB 口能不能插、安装孔位置对不对、端子会不会挡住别的接口。

## 8. 到货装配与上电顺序

| 顺序 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 | 目视检查 | 无短路划伤、丝印与实物对得上 |
| 2 | 万用表通断：`VBAT` ↔ `GND` | **不通** |
| 3 | 只焊 DC-DC 排针 → 插模块 → 上电池 | `5V_LOGIC` 与 `VM_5V` 电压正确 |
| 4 | 焊 STM32 母座 → 插板 → 跑闪灯 | 不复位 |
| 5 | 焊 PS2 排母 → 读手柄 | 通信正常 |
| 6 | 焊 DRV8833 母座 → 先只接 1 个马达 | 正反转正确 |
| 7 | 四个马达全接，**轮子离地** | 四轮方向全对（麦轮 X 型） |
| 8 | 落地限速跑 | 不复位、不跑偏 |

## 9. 常见翻车清单（打板前逐条对照）

| # | 翻车 | 规避 |
| --- | --- | --- |
| 1 | 引脚顺序靠猜 | 必须量实物 / 看丝印 |
| 2 | 板框没闭合或画错层 | Gerber 直接出错 |
| 3 | 丝印压焊盘 | 难焊、字符糊 |
| 4 | 铺铜没设 GND 网络 | 等于没有地平面 |
| 5 | 大电流走线太细 | 发热、压降、主控复位 |
| 6 | 安装孔和底盘对不上 | 板子装不上，整版报废 |
| 7 | 母座间距选错（2.54 vs 2.0） | 插件插不进 |
| 8 | USB 口被板子挡住 | 无法下载程序 |
| 9 | 忘了留 SWD | 每次都要拔板烧录 |
| 10 | 只打 1 片 | 常规一次 5 片，留 1 片做对比 |
| 11 | 关键网络没留测试点/跳线 | 出问题只能割线飞线 |
| 12 | 舵机与马达共用一条细 5V 走线 | 舵机抖动、主控复位 |
