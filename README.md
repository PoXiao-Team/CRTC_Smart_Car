# CRTC_Smart_Car

**破晓战队（PoXiao-Team）· 重庆大学机器人训练大赛 CRTC2026 参赛小车**

四轮麦克纳姆轮底盘 + 前端舵机翻转铲收集机构（**当前过渡：V1 铲 + 塑料箱装载**，见《机械篇》）＋ 阶梯式收纳舱（设计目标）；STM32F103C8T6 主控、DRV8833 驱动、PS2 手柄遥控；视觉采用「虚拟机 Ubuntu 22.04 + ROS2 + OpenCV」+「宿主机 Conda + YOLOv8」双环境方案。**双车方案：1 号车铲子（已实车跑通）、2 号车机械臂（预研）。**
