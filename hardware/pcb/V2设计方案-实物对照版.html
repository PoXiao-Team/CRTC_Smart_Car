① 系统总览

                 ┌─ 官方无线继电器 ─┐
 2S 电池(7~8.4V) ─┤                 ├─ VBAT ─┬─ 降压模块2 ─(OUT 调 5.00V)─▶ +5V ── 核心板 5V / 调试口
                 └─────────────────┘        └─ 降压模块1 ─(OUT 调 5.00V)─▶ VM  ── 两块 DRV8833(VM) + 舵机
 全局共地：所有元件 GND 连成一张网（全板唯一地网，不出现 VSS/GNDA 等别名）
链路走向
电源电池 →（继电器）→ VBAT → 两块降压模块输入；降压模块 2 → +5V（只给核心板 + 调试口）；降压模块 1 → VM（给两块驱动 + 舵机）
控制PS2 手柄 → 核心板 B3/B4/B5/B6（软件 SPI）；8 路 PWM（A8/A9/A10/A11 + A6/A7/B0/B1）→ DRV8833 ×2 → 四路马达；B7 → 舵机；A2/A3 → 调试口
使能B12 → 两块 DRV8833 的 STBY（三点同网，高电平使能）
两条必须记住的电气红线：① VM 与 +5V 是两条独立的网（两块 mini 的输出），任何情况下不许合并；② 全板只有一张 GND 网。

④ V2 草图对照检查单（照你 10-16 晚的截图逐条核）

#部位要做什么
1两块降压模块的 “VCC” 残留（重点）已按你确认锁定：降压模块2左 OUT+ → +5V（与 C8T6左 5V 同网）；降压模块1左 OUT+ → VM；两块 IN+ → VBAT。把图上所有 “VCC” 标签全部替换掉——VCC 不在 29 网体系里，且 IN+ 与 OUT+ 绝不能同名（同名 = 输入输出短接）
2两块驱动的 VM接 VM 网，不要接 +5V（+5V 是 mini#1 的，合并=两路降压并联）
3四个 DRV 块前后配对前驱输入 = A8/A9/A7/A6；后驱输入 = A10/B0/B1/A11。逐块核对，别前后装反
4DRV 右列 3、8 脚两个 GND 都接 GND，不要打 ×；右列只有 2 脚打 ×
5马达输出标签同一电机的两条线用两个不同网名（如 左前电机A / 左前电机B）——现在端子还没接通，记得连上
6舵机电源脚接 VM（截图里看着像 +5V，核一下）
7PS2 1–4 脚顺序按 ②-11 的两个方案锁一个，先别混
8位号中文位号会被 DRC 提示“不符合规则”——改成：电源→J1、降压模块1→U1、2→U2、C8T6左/右→U3A/U3B、四块驱动→U4A/U4B/U5A/U5B、舵机→J6、PS2→J7、马达端子→J2–J5、电容→C1–C6
