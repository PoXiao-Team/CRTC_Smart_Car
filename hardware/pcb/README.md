# hardware/pcb — 底板 PCB 设计

> 自制载板 **CRTC2026_SmartCar_BaseBoard** 的设计资料。目标：STM32 开发板、2×DRV8833 红板、2×DC-DC mini、PS2 接收器、SG90 舵机、马达与电池全部经板载接口连接；消除面包板接触不良、模块可拔换、对齐手册 P7"建议采用集成电路板、纯杜邦线易脱落"的结构规范。

## 关键口径

- VM 设计值 = **5.0V**（DC-DC 电机路输出；设 6V 时电池后半程压差不足会不稳压）
- PB3/PB4 为 JTAG 复用脚：固件须关 JTAG 保 SWD（`__HAL_AFIO_REMAP_SWJ_NOJTAG()`）
- DRV8833 的 STBY 接 B12、不得悬空；TIM1 须使能 MOE；TIM3 禁部分重映射
- V2 取舍：马达线直焊驱动模块输出针（无端子）；本版无去耦电容（装车后视情况补）
