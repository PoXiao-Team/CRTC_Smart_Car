# hardware/pcb — 底板 PCB 设计

> 自制载板 **CRTC2026_SmartCar_BaseBoard V1**：STM32 开发板、2×DRV8833 红板、2×DC-DC mini、PS2 接收器、SG90 舵机、4 个马达端子、电池输入全部经板载接口连接的底板。目标：消除面包板接触不良、模块可拔换、对齐手册 P7"建议采用集成电路板"的规范。

## 目录

| 路径 | 内容 |
| --- | --- |
| `CRTC2026_SmartCar_BaseBoard_V1/` | 立创 EDA 专业版工程源文件（原理图 / PCB / 面板） |
| `design/crtc_baseboard_v1.py` | 设计单一数据源脚本（运行即生成全部工程数据与 ERC 校验） |
| `design/out/` | 设计产物：BOM.csv、NETLIST.csv、接线表.md、布局坐标.csv、线宽与电流预算.md、装配核对表.md、施工单.html、ERC报告.txt |

> 设计数据以 `design/` 产物为准（接线表明确"由脚本生成，不要手改"）；改动请改脚本后重跑。

- ⬜ 下单死线：2026-10-18 中午（18:00 判断点，未完成即放弃赛前打板，用面包板参赛）

## 关键口径

- VM 设计值 = **5.0V**（DC-DC 电机路输出；设 6V 时电池后半程压差不足会不稳压）
- PB3/PB4 为 JTAG 复用脚：固件须关 JTAG 保 SWD（`__HAL_AFIO_REMAP_SWJ_NOJTAG()`）
- DRV8833 的 STBY 接 B12、不得悬空；TIM1 须使能 MOE；TIM3 禁部分重映射
