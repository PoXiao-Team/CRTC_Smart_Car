# 装配核对表（CRTC2026_SmartCar_BaseBoard V1）

> 板子回来后**先做完本表再通电**。全部用万用表蜂鸣档（断电测量）。

| # | 核对项 | 预期 | 结果 |
|---|---|---|---|

| A02 | J1.BAT- ↔ U1.IN- / U2.IN- / U3A.G / U3B.G1 / U3B.G2 / U4A.GND1 / U4B.GND2 / U4B.GND3 / U5A.GND1 / U5B.GND2 / U5B.GND3 / J7.GND | 全部响（GND 网） | ☐ |

| A04 | U1.OUT+ ↔ U3.5V / C3.+ / J8.+5V | 响（+5V 网） | ☐ |
| A05 | U2.OUT+ ↔ U4B.VM / U5B.VM / J6.V / C1.+ / C2.+ / C4 | 响（VM 网） | ☐ |
| A06 | U1.OUT+ ↔ U2.OUT+ | **不响**（+5V 与 VM 不得短接） | ☐ |

## B. 模块插入方向（插错必烧）

| 模块 | 核对方法 | 结果 |
|---|---|---|
| U1/U2 mini 降压 | 模块丝印 IN+ 对准底板 IN+，OUT+ 对准 OUT+；反插会反灌烧核心板 | ☐ |
| U4/U5 DRV8833（2×8，16 脚） | 左列 NC/AIN2/AIN1/STBY/BIN1/BIN2/NC/GND 对准 U4A/U5A；右列 VM/NC/GND/AO1/AO2/BO2/BO1/GND 对准 U4B/U5B（BO2 在上）；插反插错位必烧 | ☐ |
| U3 STM32 核心板 | USB 座朝板外；5V 脚对准底板 5V（插反必烧核心板） | ☐ |
| J6 舵机 | 黄=信号(S)、红=V、棕=G；插反舵机立即烧毁 | ☐ |
| J7 PS2 | VCC 接 +3V3；确认不是接到 +5V | ☐ |

## C. 首次上电（分级，冒烟即断电）

| 步骤 | 操作 | 预期 | 结果 |
|---|---|---|---|
| C1 | 不插任何模块，只接电池测 J1 两端 | 7.0～8.4V | ☐ |
| C2 | 插 U1，测 U1.OUT+ | **5.00V ±0.05**（超过 5.25V 立刻断电，会烧核心板） | ☐ |
| C3 | 插 U2，测 U2.OUT+ | **5.00V ±0.10** | ☐ |
| C4 | 断电，插 U3 核心板，再上电 | 核心板电源灯亮，无冒烟/发热 | ☐ |
| C5 | 插 U4/U5（先不插 STBY 之外的负载） | 无发热 | ☐ |
| C6 | 烧录固件，给 DRV_STBY 高电平，单轮点动 | 对应轮转动，方向不对就整组对调端子线 | ☐ |
| C7 | 四轮齐动 + 舵机 | 无复位、无明显压降（VM 跌落 ≤0.5V） | ☐ |
